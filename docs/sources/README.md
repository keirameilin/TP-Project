# Source papers

The papers behind the nutrition rules are kept on each developer's machine, not in this
repository, because they are copyrighted. `*.pdf` files in this folder are ignored by git.

## uefa-nutrition-statement.pdf

Collins J, Maughan RJ, Gleeson M, et al. UEFA expert group statement on nutrition in elite
football. Current evidence to inform practical recommendations and guide future research.
*Br J Sports Med* 2021;55:416–442. doi:10.1136/bjsports-2019-101961

Download it from https://doi.org/10.1136/bjsports-2019-101961 and save it here as
`uefa-nutrition-statement.pdf`. Page numbers in `src/features/targets/rules.ts` are the journal's
page numbers (416–442); PDF page 1 is journal page 416.
